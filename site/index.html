Algumas respostas
para começar.

O cliente precisa usar outro sistema?

A proposta é manter a experiência dentro do ERP. O FiscoNexa fornece a API, e o sistema integrado apresenta os documentos e as ações ao cliente.

É necessário certificado digital?

Sim. O cadastro utiliza o certificado A1 da empresa e sua senha, com autorização para a operação. O material é protegido por criptografia antes de ser armazenado.

Todo documento localizado já tem XML?

Nem sempre. A SEFAZ pode disponibilizar primeiro um resumo. A API informa se o XML já está disponível ou se o processamento está pendente. O acesso também depende das regras e dos prazos fiscais aplicáveis.

Posso integrar várias empresas?

Sim. Cada empresa possui uma credencial de integração própria, e a consulta de documentos é vinculada a esse acesso.

A plataforma já está aberta para contratação?

O FiscoNexa está em preparação para o lançamento. Esta página apresenta a proposta e os recursos da integração inicial com ERP.
