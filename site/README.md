# Landing page FiscoNexa

Publique `index.html` como pagina inicial de `fisconexa.com.br`.
O arquivo e independente: CSS e JavaScript embutidos, sem fontes externas,
bibliotecas, cookies ou coleta de dados. Tambem abre diretamente no navegador.
Entradas ao rolar, detalhes animados e simulacao manual no painel ilustrativo
usam recursos nativos. Nao ha polling nem chamadas a API; os temporizadores
terminam ao concluir a simulacao ou ocultar a aba. Movimento reduzido e
respeitado, e o conteudo continua disponivel com JavaScript desligado.

A pagina apresenta a proposta ERP, identifica os exemplos como ficticios e
informa a preparacao para lancamento. Nao anuncia contratacao aberta, SLA,
precos ou canais de contato ainda nao definidos.

O DNS precisa apontar para a hospedagem que servir este arquivo. O subdominio
`api.fisconexa.com.br` continua reservado a API.
